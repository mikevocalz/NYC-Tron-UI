Status key

  • existing: defined in the repo today.
  • proposed: a step of the closed scale that the literal-to-token codemod adds. Rows say so in words, not only by position.
  • proposed-scoped: a component-scoped token with the value of the literal it replaces, such as <Component>.radius.11.

The machine-readable files are tokens.json and tokens.md.
