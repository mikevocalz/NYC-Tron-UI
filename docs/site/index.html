NYC-Tron UI

Themeable, independently maintained UI for React Native and Expo on iOS, Android and web, with isolated Windows and macOS adapters under native acceptance.

npx shadcn@latest add @nyc-tron/Button

Registry install is unverified until a clean app installs from the live URL. Registry URLs use ref `main`, a moving ref, until the owner cuts a release tag. They resolve only after this branch is merged to main. Before that, test against a local server. Use the release tarball until then.

You are offline. The install command needs a connection.
