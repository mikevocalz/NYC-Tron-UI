# Text surfaces and document references

Reviewed the last seven P12 UI rows: H-01, H-02, H-12 and H-17 through H-20. All 22 document library rows now have implementation reviews; acceptance remains unverified.

TextSelectionAndCaret uses an actual React Native TextInput for platform text editing, native selection/caret, keyboard, bidirectional writing and IME. Text seeds replace only at explicit content-revision boundaries. Draft text lives in per-instance Zustand; native input handles stay in refs. Read-only text remains selectable. Numeric UTF-16 selection fields provide an additional explicit route. Native rich text is a separate host adapter requirement, not an attributed-text claim for TextInput.

PaginatedTextCanvas presents supplied laid-out pages with native plain-text editing, measured overflow callbacks and stable page identities, or requires a native-rich-text rendering adapter in rich mode. The consuming document engine owns page splitting, typesetting and redistribution; no renderer is invented here. Pages/text are bounded. Zoom/paper geometry change inside the component; app window dimensions and orientation remain untouched. The editor integration follows the native rich-text skill's separation of native buffers and JS metadata; current Software Mansion docs confirm that native rich-text buffers should not round-trip through controlled React content on every key. No new editor dependency or external code was vendored.

TextWrapAndFrames validates acyclic frame threads and exposes anchors/wrap/geometry/overset data. FootnoteCitationEditor searches supplied sources and requests citation/footnote/endnote edits, style and bibliography updates using actual formatted previews. SpellGrammarPopover shares the anchored overlay owner, respects usable regions and exposes replace/ignore/dictionary actions from actual checker output with offline states; its content exports separately for native popover adapters. MailMergeFieldPicker uses actual recipient previews and admitted data fields. LayoutSpreadNavigator supports facing pages, masters and overset notices with supplied thumbnails.

Validation: combined UI TypeScript build passed.
