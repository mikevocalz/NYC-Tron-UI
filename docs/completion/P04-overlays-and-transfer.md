# P04 overlay, status and transfer implementation checkpoint

Command search preserves its controlled selection, keyboard focus cycle and opener focus, validates bounded command identities, resets search on scope replacement and rejects stale callbacks. Context menus retain pointer/stylus context-click, touch long-press, keyboard and assistive paths, preserve the target's primary action and discard obsolete measurements/actions. NativeActionMenu still renders actual Expo SwiftUI/Compose menus; scope replacement reconstructs the OS menu and disabled/unmounted events cannot dispatch. Its web presentation is scoped too. Trigger targets have a 44-point minimum.

NativePopover retains its established rect-form parent-coordinate contract and trigger-form window coordinates. Actual SwiftUI Popover and Compose DropdownMenu surfaces remain separate from the web AnchoredPopover. Sizes and preferred side derive from caller-provided usable regions; the OS owns final native placement/focus. Trigger measurements refresh on window/region changes without closing a still-open text surface. New sessions discard obsolete anchor results and dismissal events. Empty usable regions hide portable and native overlays safely while retaining the trigger. No app window/orientation or platform manifest was changed.

Preset galleries provide host-driven previews, selection, favorite toggles, filters and grid keyboard focus. Preview ownership prevents a departing tile from clearing another tile's preview; scope replacement suppresses old actions. Status controls expose real selection/activity, progress, zoom and units, with scoped menus and bounded choices. Recording elapsed time is outside the polite live region so clock ticks do not repeatedly announce the status.

Shortcut recording reads current commands/callbacks and stops when its scope, visibility, usable pane, permission or recording command disappears. Removed native listeners ignore retained late callbacks. Newly introduced conflicts still require confirmation. The HUD fits a caller's usable pane and uses app shadow/backdrop tokens. FocusAndA11yLayer was audited: per-instance Zustand preferences, scoped OS subscriptions and asynchronous-read cleanup, reduced-motion/contrast/modality hooks and platform announcements remain intact. The native consumer now mounts that provider. Native speech/narration output is not claimed.

File transfer retains actual platform picker transports and typed format/quality/metadata/destination requests. Picker identity follows scope. A pending export promise blocks duplicate requests and edits, shows real rejection errors and suppresses late results after replacement. The host still owns actual processing, files and cancellation. Boolean metadata uses checkbox semantics; format/destination choices provide keyboard selection and roving focus. Inputs have per-instance IDs, stale field updates reconcile current settings, and the scrollable sheet stays inside a supplied usable pane.
