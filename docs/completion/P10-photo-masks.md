# P10 mask and localized retouch checkpoint

F-09 LocalMaskBrush and F-16 CleanupAndRetouchPanel share one native responder and bounded settings owner. Marks retain normalized image coordinates and reported force separately from unavailable force. Radius is in source pixels, feather/flow are explicit, and one completed gesture makes one typed request. Escape, OS termination, a second pointer, a document boundary or a changed image frame abandons a draft. A 4,096-point overflow cancels with an error rather than silently truncating an engine request. Live path display is frame-coalesced and bounded to 257 segments. Numeric stamping supplies an alternative to freehand input. The host owns real mask/heal/remove processing and source pixels.

F-10 LinearRadialGradientMask reuses GradientOnCanvasHandles with a new geometry-only mode; paint stops/rail commands are neither drawn nor actionable in that mode. Source-pixel geometry maps into the existing view transform. Feather/inversion produce a real bounded coverage PNG preview, including during a drag. Document/value/viewport boundaries invalidate captured edits and clear previews. The normal vector paint editor retains its defaults and passes its browser regressions.

F-11 LuminanceColorRangeMask controls normalized luma bounds, color tolerance, softness, invert and replace/add/subtract/intersect. Document-only sampling carries photo ID, expected revision and bounded image-pixel coordinates. Returned floating channels and profile identity remain intact; display previews do not replace them. A late sample from another document cannot commit.

Three model tests cover normalized force samples, limits, reference gradient coverage and profile preservation. Eight mask browser paths cover real drag preview/release, Escape, numeric mask/retouch stamps, geometry keyboard input, original profile floats, stale document reads, actual coverage PNG pixels during a drag and late releases after a photo switch. Nineteen existing vector browser regressions passed alongside the initial mask run. UI/native consumer TypeScript, workspace checks and artifact verification are required before commit.

All 18 canonical P10 photo controls now have reusable implementations. This is not complete P10 platform acceptance or a claim that RAW, retouch, export or catalog processing engines have been implemented in this UI package. The saved native brush flow passed twice unchanged on iOS (16.4s/10.5s) and twice unchanged on Android (42.2s/43.9s). It verifies a native drawing gesture, one add-mask request and cleared preview; runner output and the retained Android idle warnings are in P10-native-brush-proof.json. This is a path-specific runtime result. Other photo runtime paths, narration, physical stylus force, desktop and headset evidence remain unverified, and engine integration stays tracked separately.
