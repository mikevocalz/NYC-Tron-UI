# P05 snapping and pivot review

B-04, B-05 and B-08 retain their existing overlay/model owners and independent exports. The grid overlay and smart-guide renderer are passive document-coordinate feedback; geometry remains physical LTR in RTL layouts. Snap settings and pivot edits now take scope/revision and reject late callbacks after scope, geometry or permission replacement. Pivot drag drafts clear at those boundaries without remounting the canvas. Invalid corners, targets and guide feedback reject before native view allocation.

Grid/snap configuration validates booleans, finite values, unique bounded guide/artboard IDs and 10,000-item guide/artboard budgets. Smart guides validate a 50,000-layer input ceiling, consider the nearest 200 rectangles and bound feedback to the model's maximum alignment/spacing output. Spoken targets use own-property lookups, truncate labels and summarize long target lists rather than reading hundreds of names. Existing ProCraft source and license notices remain intact.

The review also fixes the canonical shared PrecisionScrubber/NumericScrubField: a scope/revision/configuration boundary retires its draft controller, while committed callback guards stop old preview/commit closures from reaching a new owner. An old async rejection stays with its retired local controller. Controlled value acknowledgements preserve focus. This extends the existing numeric implementation instead of introducing another grid field owner.

Validation: UI build/types, all 823 source tests and 37 targeted model tests passed. Targeted browser runs passed all 11 canvas-guide, 11 precision-ownership and six scrubber tests. Regressions cover held releases after document replacement, disable and unmount; abandoned grid text drafts; old async rejection; focus through controlled acknowledgements; pivot cancellation; exact guide dimensions; metadata budgets and inherited-name protection. Native pivot/snapping and full eight-platform acceptance remain unverified. Review count is 96 of 341; P05 remains in progress.
