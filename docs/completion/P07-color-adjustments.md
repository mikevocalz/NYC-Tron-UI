# Color adjustment and analysis controls

Adds independent controls for C-02, C-04, C-11, C-16, C-17, C-19, C-20, C-21, C-22, C-23 and C-24. Imports use `@nyc-tron/ui/components/forge/color/<Component>`; the shared curve, analysis and mesh contracts are separately exported.

- SVColorField and HueSlider retain the host's hue/alpha or saturation/value respectively. The two-dimensional field composes bounded saturation/value strips without requiring an optional gradient renderer. Keyboard and native accessibility actions provide alternatives to pointer editing.
- EyedropperTool samples explicitly selected document coordinates/source/revision through a cancellable provider. It preserves original profile-bearing floating channels, with a separate display preview and explicit apply operation. It never invokes an OS screen eyedropper or substitutes a screenshot.
- GradientStopEditor reuses the existing paint schema and insertion/interpolation rules. Stop position, color, alpha, addition, removal and selection form real host transactions. GradientMeshEditor edits a row-major bilinear mesh and rejects folded or singular cells using all four corner Jacobians; the application supplies actual surface rendering behind its topology overlay.
- LiveHistogram pools actual counts without losing bins. VideoScopesPanel renders frame-tagged histogram, waveform and vectorscope measurements with bounded density pooling. Unknown decoded data remains distinct from a measured empty signal. Coordinates in scope data are normalized view coordinates; y increases downward.
- LevelsEditor enforces increasing input bounds, ordered output bounds and finite gamma. CurvesEditor supports linear and monotone cubic transfer functions, exact input/output entry, stable point IDs, insertion/removal, pointer preview, a single release commit, keyboard adjustment and Escape cancellation. It remeasures the graph when a drag starts, including after scrolling. Endpoint input positions stay fixed and points cannot cross neighbors.
- ColorGradingWheels controls shadow/midtone/highlight hue, saturation and exposure, plus balance/blending. The existing disc has an additive `showBrightness` option so a grading wheel does not expose a brightness control that its tonal model cannot apply. HSLSecondaryEditor retains wrapping hue ranges, ordered saturation/luma bounds, mask refinement, corrections and explicit mask preview/inversion.

The consuming engine owns pixel processing, tonal weighting, mesh rendering, document sampling, profile conversion and transaction/revision rejection. These controls do not manufacture successful engine output.

Model checks cover curve endpoints/interpolation and nonovershoot, count-preserving histograms, scope edge samples, adjustment bounds and nonfolding mesh edits. Rendered browser checks exercise actual controlled document changes, drag preview/commit/cancel, scrolling, insertions, rejected geometry, original HDR sample application, and narrow LTR/RTL layouts. Native, screen-reader and physical-device acceptance remain separate gates.
