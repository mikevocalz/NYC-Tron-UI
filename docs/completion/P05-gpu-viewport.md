# P05 GPU viewport checkpoint

B-01 now exposes an actual Skia 3.9.1 SkiaGraphiteView and a separate frame-submission model. Native uses Graphite/Dawn; web uses the upstream CanvasKit WebGL implementation of the same recording API. The optional peer is isolated to the component subpath. The native consumer pins the exact package and Metro shares its runtime. No Forge engine or document model is imported: the host supplies synchronous drawing from its own independent document state and owns its renderer resources.

Each complete frame clears the surface, maps layout points to the controlled viewport, translates and scales document coordinates, closes the recording and queues it only while its scope/revision is current. Finished recordings are disposed after the native queue takes ownership. Failed or retired recordings are closed and disposed without submission. Context wrappers remain imperative resources outside Zustand. Scope/revision and controlled viewport changes request drawing; replacing callback identity alone does not create a render loop.

GPU availability/loss metadata and app foreground changes are observed, with subscription cleanup and mounted guards. Unavailable GPUs show the actual reason. Paused/background rendering submits nothing and resumes from current host state. Draw failures appear visibly and reach onRenderError; a subsequent revision can recover. onFrameSubmitted means queued submission, never display presentation. The demo demonstrates renderer callbacks with app-authored colors, no production Rust operation.

Validation passed: 820 source tests, repository builds/types, independent dependency/export checks and all 13 validation tarballs. The complete browser run passed 582 tests; three final GPU cases additionally passed after the visible-error recovery was added. Five recording lifecycle tests cover exact transforms, release order, draw failure, stale scope, zero size and rejecting asynchronous callbacks. Actual CanvasKit pixels verify geometry and replacement, pause/resume with the same surface, visible renderer failure and recovery. Readback uses the source canvas color space: installed 3.9.1 creates a Display P3 browser 2D presentation canvas. This checks buffer channels, not physical gamut, standards colorimetry or native presentation.
