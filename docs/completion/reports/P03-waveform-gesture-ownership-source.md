# P03 waveform lane gesture ownership source checkpoint

WaveformLane no longer keys its body by scope/revision, columns, height or visible range. Its native lane and focusable accessibility target remain mounted across these updates. Existing Zustand local preview state and native responder are retained; no audio engine, native module, dependency or gesture-stack migration is introduced.

A per-instance pure gesture session captures the actual measured width, authoritative visible range and committed boundary at grant. A tap computes one seek from those captured coordinates; a drag crossing six points previews and commits one range. Without range commit capability, ordinary released gestures still seek. Release consumes the session exactly once.

Semantic/layout/admission changes cancel that session and clear local scroll preview. Native onLayout width changes also cancel before subsequent move/release can interpret old coordinates. A cancelled or terminated session cannot fall through to tap seek. Same-source measured-width cancellation restores the current admitted host range preview; replacement authority is not overwritten by an old range. The host remains source/revision and visible-range owner. Stale captured accessibility actions reject at the committed boundary. The fallback uncontrolled playhead is source-tagged: a different source reads zero synchronously during render, while persistent responder seeks record the latest committed source tag. Pure geometry updates preserve it. Multi-touch grants reject and an additional active pointer cancels the session before later release.

Five focused Node regressions pass: ordinary tap/drag/no-scroll behavior; cancellation, replacement and late-release suppression plus a new-width tap; and source assertions protecting stable body identity, actual measurement cancellation and release admission. These are model/source tests, not mounted focus or native gesture acceptance. UI and slots-harness TypeScript checks pass. Visual, screen-reader, keyboard, native pointer and fold/resize runtime acceptance remains deferred to the user's review gate.
