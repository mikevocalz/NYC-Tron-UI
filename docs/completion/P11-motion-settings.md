# P11 transform, camera, matte and emitter checkpoint

Implemented G-07 Transform3DInspector, G-08 CameraAndLightControls, G-09 MatteAndMaskPanel and G-12 ParticleEmitterControls as independent public exports. A shared axis field preserves untouched floating coordinates. Rotation retains complete turns and signed/zero scales; transforms use document/scene coordinates and never write application window configuration.

Camera controls cover projection, position/target, focal/sensor width, near/far, orthographic size, focus distance, aperture and depth of field. A degenerate target is rejected with a visible error. Lighting retains linear RGB and its working profile identity, intensity, type, position/rotation, spot cone and shadows. Matte controls retain alpha/luma inversion, source identity and feather; self and host-reported cyclic/unavailable choices cannot be selected. Particle settings retain rate/life/speed/spread/gravity, texture identity, size, opacity and an exact uint32 random seed. The host owns simulation, rendering and graph validity.

The A-13 UnitInput review confirms px/pt/mm/percent, frame/second/sample and dB conversion through its bounded arithmetic parser. This review also fixed its draft ownership: disabling drops a draft, an optional document/property scope abandons old input, and an unmounted/scoped-out field cannot commit late. RAWDevelopPanel remounts its field subtree when photo identity changes. These changes do not change values simply because a display unit or document revision changes.

Three motion model tests and targeted browser paths cover rotations, camera validation, matte source availability, deterministic seed/gravity, disabled numeric drafts and photo/document changes, along with existing color and inspector regressions. All 503 browser tests then passed, including existing narrow/RTL and capture lanes. Workspace verification passed 776 source tests, builds, types and all 13 packed artifacts. Standalone native consumers import built public exports. No compositor, physical 3D host, native narration or complete P11 acceptance is inferred. The other 11 canonical motion components remain open.
