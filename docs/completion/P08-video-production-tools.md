# P08 video production tools

The final 11 P08 library rows now have independent controlled implementations: export, speed ramps, captions, word timing, reframing, stabilization, effects, tracking, cover selection, quality and sticker motion. P08 library implementation is 41/41; engine and platform acceptance remain separate.

ExportMonitor adds explicit codec capabilities, width/height multiples and limits to the existing render preset/profile/frame-rate/destination/progress queue. Enqueue receives the actual output geometry/codec snapshot. VideoSpeedRampCurve reuses MotionCurveEditor in value mode so knots represent speed rather than its derivative, preserves supported reverse/freeze policy and sends one retime transaction; authoritative source-duration estimates and undo come from the engine.

AutoCaptionTranscriptTimeline edits actual ASR segments and speaker metadata, exposes recognition language/progress/cancel, and follows the real playback frame without inventing captions or a clock. CaptionWordTimingHandles reuses frame-aligned in/out handles, checks neighboring-word collisions, clears temporary previews and preserves keyboard control identity across acknowledgements. InOutRangeHandles adds an optional showCommands setting so word/sticker ranges do not expose an invalid clear-range command. Recognition/processing remains host-owned.

AutoReframeGuides reuses the guided crop owner for aspect ratios and manual correction; tracking state, subject labels and progress come from the host. VideoStabilizationInspector provides strength, bounded temporal smoothing/quality, actual before/after preview and reported retained-crop measurements. Both expose cancellation. MotionTrackingOverlay uses real frame-tagged bounds/confidence when available, explicitly distinguishes missing/lost tracking, reuses SelectionBounds for paused-frame correction and submits forward/backward tracking with cancellation.

VideoEffectsBrowser reuses the schema-driven effect library/stack/inspector and adds clip preview, masks and intensity. CoverFramePicker chooses actual decoded source frames or host-selected image assets and commits cover metadata through the export adapter. VideoQualityInspector displays actual codec, dimensions, bit depth, frame rate, color space and bitrate, alongside preview/export capabilities and warnings. StickerMotionLane owns no image engine: it controls host sticker assets, independent ranges, transforms and the existing editable motion keyframe timeline.

All state is controlled or held in per-instance Zustand stores; controllers/native objects remain in refs/closures. No new native module, app window/orientation, decoder, recognition model, tracking model or encoder was fabricated. Existing original/provenance notices remain intact. Shared scoped controls now expose an explicit boundary-checked cancellation action and pending operation identity.
